# Video Script: "Die Plattform hinter Europas größter Trailer-Flotte"

## Format & Spezifikationen

- **Länge:** 45-60 Sekunden
- **Aspect Ratio:** 16:9 (LinkedIn / Website)
- **Untertitel:** Immer eingeblendet (80% schauen ohne Ton)
- **Musik:** Ambient Tech-Track, seriös, kein Beat-Drop
- **Text-Overlays in Post-Production** (CapCut / DaVinci Resolve)
- **Keine Voiceover nötig** — Text-Overlays wirken moderner

---

## Style Anchor

> Dieser Block wird an **jeden** Higgsfield-Prompt angehängt, um visuelle Konsistenz zu gewährleisten.

```
Cinematic corporate film, anamorphic lens, shallow depth of field,
color graded with teal shadows and warm orange highlights (#E67E22),
natural lighting, shot on ARRI Alexa, 24fps film grain,
muted color palette with selective orange accents, 16:9 aspect ratio
```

## Szene 1 — Hook: "Die Daten-Autobahn" (0-5s)

**Video Prompt:**
```

dusk, blue hour lighting. A row of modern white cargo trailers
driving in formation. Subtle holographic orange data overlays float
above each trailer — GPS coordinates, temperature readings, small
status icons. The overlays are clean and minimal, not sci-fi.
Camera slowly tracks alongside the convoy from above.
[Style Anchor]
```

## Konsistenz-Checkliste

- [ ] **Orange (#E67E22) als einzige Akzentfarbe** — alles andere gedämpft (Teal/Grau/Weiß)
- [ ] **Keine frontalen Gesichtsaufnahmen** — Over-Shoulder, Silhouetten, Seitenprofile (vermeidet AI-Gesichter-Probleme)
- [ ] **Kein lesbarer Code/Text auf Bildschirmen** — nur abstrakte Visualisierungen, Karten, Gauges
- [ ] **Style Anchor an jeden Prompt** — gleiche Kamera, Licht, Farbpalette
- [ ] **Text-Overlays in Post-Production** — Higgsfield nur für Visuals
- [ ] **Musik durchgängig** — ein Track, kein Wechsel
