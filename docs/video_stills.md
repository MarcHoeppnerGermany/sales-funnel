# First Frames / Stills — IoT-Plattform (B2B Sales Director)

## Verwendung

- **First Frames** für Seedance 2.0 Video-Generierung
- **Standalone-Bilder** für LinkedIn-Posts, Pitch Decks, Website
- **Thumbnail** für das fertige Video

9 Shots (3 Szenen × 3). Style Anchor in jedem Prompt — ohne Hex-Codes, ohne fps, ohne Aspect Ratio (wird als Parameter gesetzt).

**Regisseur-Referenz:**
- Szene 1: Murro (Tracking, Teal-Orange) + Fincher (DCU-Detail)
- Szene 2: Morris (Operations Manager, statisch, echt) + Murro (Datacenter, Team)
- Szene 3: Morris + Fincher Hybrid ("Authoritative Precision")

**Zielgruppe:** CTO/CIO branchenübergreifend (IoT im großen Maßstab)
